# 🇮🇩 Warna Nusantara

**Warna Nusantara** adalah sebuah proyek sistem desain visual dan eksplorasi palet warna digital yang mengekstraksi keindahan kekayaan budaya, alam, batik, tekstil tradisional, serta lanskap Indonesia ke dalam kode warna yang dapat digunakan oleh pengembang web dan desainer.

---

### ✨ Fitur Utama
- 🎨 **Palet Warna Tematik**: Warna-warna khas dari Tenun Ikat, Batik, Alam Nusantara, hingga Seni Tradisional.
- 💻 **Siap Pakai**: Tersedia dalam format HEX, RGB, HSL, CSS Variables, dan Tailwind CSS config.
- 📱 **Ramah Aksesibilitas**: Kombinasi warna yang diuji untuk standar kontras rasio (WCAG).
- 🚀 **Ringan & Mudah Diintegrasikan**: Dapat langsung diimpor ke proyek web atau aplikasi Kamu.

---

### 📦 Koleksi Warna Contoh
- **Sogan Solo**: *Kehangatan cokelat tradisional khas Batik Jawa.*
- **Tenun Toraja**: *Perpaduan warna merah, hitam, dan kuning khas ukiran Toraja.*
- **Koral Bunaken**: *Keindahan warna pesisir dan laut timur Indonesia.*
- **Hijau Parahyangan**: *Kesegaran perbukitan dan alam Pasundan.*
